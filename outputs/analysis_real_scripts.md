# 真实剧本上的外部效度检验

> 数据：《大话西游》真实剧本 40 句（STAGE，zhuiwen-ai/STAGE）
> 人标：DSH 对话内标注 40/40　模型：deepseek-chat　日期：2026-10-31

## 0. 为什么做这一节

此前三批实验的金标都是 `reference.appraise()` 的关键词表。而它在真实台词上**退化成常数**：

```
真实 40 行 → 规则给 5.0 的有 36 行（90%）
```

一个 90% 输出同一个值的"金标"，不能用来证明任何事。所以必须换人的标注做尺子。

## 1. 三个尺子在同一批真实台词上的表现

| 臂 | arousal 均值 | 标准差 | MAE vs 人 | 95% CI | 秩相关 ρ vs 人 |
|---|---|---|---|---|---|
| 人标 | 5.60 | 1.22 | — | — | — |
| `judge_plain`（不给线索表） | 6.33 | 1.34 | **0.93** | [0.72, 1.11] | **+0.76** |
| `judge_cue`（给线索表） | 7.10 | 0.94 | 1.64 | [1.38, 1.93] | +0.59 |
| 规则表（关键词） | 5.22 | 0.77 | 1.07 | [0.86, 1.27] | **+0.19** |

补充：`judge_nudge`（plain + 一段括号说明）MAE **1.00**，标准差 1.68，
介于 plain（0.93）与规则（1.07）之间。四个臂在真实数据上的排序是：

```
judge_plain 0.93  <  judge_nudge 1.00  <  规则表 1.07  <<  judge_cue 1.64
```

也就是说，**只要把线索表塞给模型，真实数据上就会明显变差**；不塞表的三个配置彼此在
一个 CI 宽度之内。

## 2. 配对检验（按行重采样，B=5000）

| 对比 | 差值 | 95% CI | 判定 |
|---|---|---|---|
| `cue` − `plain` | **+0.71** | [+0.44, +1.02] | **显著更差** |
| `plain` − 规则 | −0.14 | [−0.46, +0.15] | 不显著 |
| `cue` − 规则 | +0.57 | [+0.22, +0.93] | 显著更差 |

## 3. 三条结论

1. **模板数据上最强的臂，在真实数据上显著最差。**
   `judge_cue` 在模板上是 0.96 命中率（碾压其他臂），到了真实台词上 MAE 1.64，
   比不给线索表的 0.93 差 0.71，且 CI 不跨 0。
   **它学的是"对齐关键词表"，不是"读情绪"。**

2. **模型确实在读语义，不是猜均值。**
   `judge_plain` 与人的秩相关 +0.76，标准差 1.34（人 1.22）——
   既有排序能力，也有区分度。规则表 ρ=+0.19，几乎等于常数。

3. **但"模型比规则准"这句话说不出口。**
   MAE 差 0.14，CI 跨 0。正确的表述是：
   **模型与规则在绝对误差上打平，但在排序能力上差 4 倍（0.76 vs 0.19）。**
   MAE 在这种"人标集中在中间"的分布上不敏感，排序才是。

## 4. 局限（必须写在前头）

- **n=40，单一影片**（《大话西游》）。CI 宽度约 ±0.2，臂间小于这个量级的差距不下结论。
- **真实剧本没有潜台词**，所以这批是"无潜台词线索"条件，与模板组不完全同构。
- **场景类型无法自动判定**（标题只有「第1场」），统一置为「日常」。
  它不影响 arousal 金标（`appraise` 不看 scene_type），但影响派生参数。
- **人标只有一位标注者**。该标注者在模板数据上的自我一致 κ=0.935，
  但没有第二人复核。
- 用上下文（前后各一句）辅助判断，与模板组的协议略有不同。

## 5. 复现

```bash
python stage_adapter.py                 # STAGE script.json → tasks
python eval_real.py                     # 模型跑 40 句，输出 outputs/real_eval.json
python eval_real.py --arm judge_cue     # 对照臂
```
