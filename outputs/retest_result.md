# 自我一致性（test-retest）

> 同一批人、同一批行、隔一段时间盲标两次　样本 20 行

## 结果

| 指标 | 值 |
|---|---|
| 二次加权 κ（自己 vs 自己） | **0.935** |
| 完全一致率 | 55% |
| ±1 档内 | 95% |
| 平均绝对差 | 0.50 档 |

## 读法

**你稳定。** 这个 κ 高于主报告的 0.44（人 vs 规则），说明主报告里的分歧主要来自规则表，不是你标得飘。
