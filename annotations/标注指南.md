# 标注指南（arousal / valence / intent）

目标：为每一句台词独立给出「说话时内心的激活度、情绪效价、主导意图」，
作为**人类金标准**，用来检验 `reference.appraise()` 那张关键词表靠不靠谱。

## 三条纪律

1. **只凭这一句 + 它给的场景信息判断**，不要回看原剧本，也不要去猜作者的设定。
2. **不要看模型的输出**，也不要看别人的标注。表里没有模型答案，是故意的。
3. 判断的是**角色此刻内部的状态**，不是他「表现得多激烈」。
   压着嗓子说出的暴怒，arousal 可以是 9；笑着说「我没事」，可以是 3。

## arousal（1–10 整数）

| 分值 | 状态 |
|---|---|
| 1–2 | 极低唤醒：困倦、放空、机械应答 |
| 3–4 | 低唤醒：平静、敷衍、日常寒暄 |
| 5–6 | 中唤醒：专注、轻度在意、隐忍的克制 |
| 7–8 | 高唤醒：紧张、急切、愤怒上涌、强烈期待 |
| 9–10 | 极高唤醒：濒临失控、惊恐、暴怒、崩溃边缘 |

觉得在 6 和 7 之间，选你更倾向的那个整数；拿不准时选中间值 5。

## valence（-1.0 到 +1.0，一位小数）

-1.0 = 极度负面（恐惧、羞耻、绝望）　0.0 = 中性/复杂难辨　+1.0 = 极度正面（幸福、狂喜）
写 -0.7、0.3 这样的小数即可，不必凑整。

## intent（单选，不要自创）

威胁 / 认错 / 挽留 / 表白/安抚 / 隐忍 / 玩笑 / 惊喜 / 危机 / 质疑 / 忐忑 / 陈述 / 其他

一句话可以有复合情绪，但请选**这句话在推动剧情上最主要的那一个**。
哪个都对不上就选「其他」——硬填一个心里不服的标签，比诚实的「其他」更伤数据。
（注意「表白/安抚」中间有一条斜杠，是两个词共用一档，不是笔误。）

## 填写方式

**列名必须照抄表头，一个字都不要改**——`score` 按下面这三个带单位的表头读列，
Excel 里手工加一列 `arousal` 不会报错，但那 166 行会被**静默跳过**，报告显示 0 行：

- `arousal(1-10)`　← 只填整数
- `valence(-1~1)`　← 只填小数
- `intent`　← 只填上面 12 个词之一

其余列（序号、场景、台词……）不要动。推荐用标注台填（`python web/annotate_server.py`），
它写的就是同一张表、同一套表头，不会出这个问题。
填不动的行留空即可，`score` 只统计填了的行。`备注` 列可以写「这句我读成 X」，
有分歧的行会进报告，备注能帮后面复盘。
